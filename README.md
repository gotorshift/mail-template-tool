# メール作成ツール

カラ・レコ、勤給解決に関するメール文面を作成するブラウザー用ツールです。

## 使い方

`index.html` または `メール作成ツール.html` をブラウザーで開いてください。インターネット接続やサーバー、追加のパッケージは必要ありません。

カラ・レコの「ユースウェア」タブでは、研修日時、Zoom参加情報、研修用アカウントを入力して案内メールを作成できます。奉行クラウド・クロノスの各環境は、必要に応じて選択してください。

## GitHub Pages で公開する

1. このフォルダーのファイルを GitHub の **Public** リポジトリにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. 公開するブランチ（通常は `main`）とフォルダー **/(root)** を選び、**Save** を押します。
5. Pages の設定画面に表示される URL からアクセスします。公開まで数分かかることがあります。

## データとプライバシー

- 入力したメール情報や設定は、ブラウザーの `localStorage` に保存されます。ツール自体はそれらをサーバーへ送信しません。
- 共有端末では、入力情報がブラウザーに残る可能性があります。利用後は必要に応じてブラウザーのサイトデータを消去してください。
- 公開サイトは誰でも閲覧できます。実際の顧客情報や個人情報を公開ページに入力したり、公開リポジトリへ登録したりしないでください。
