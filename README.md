# メール作成ツール

カラ・レコ、勤給解決に関するメール文面を作成するブラウザー用ツールです。

## 使い方

`index.html` または `メール作成ツール.html` をブラウザーで開いてください。通常のメール作成にはサーバーや追加のパッケージは必要ありません。

ログイン画面を追加していますが、ブラウザー内だけで動く簡易ゲートです。ソースコードの確認やブラウザー上の操作で回避できるため、機密情報の保護や公開範囲の制御には使用しないでください。認証状態はブラウザーのタブを閉じるまで保持されます。

カラ・レコの「ユースウェア」タブでは、研修日時、Zoom参加情報、研修用アカウントを入力して案内メールを作成できます。奉行クラウド・クロノスの各環境は、必要に応じて選択してください。

カラ・レコの「導入支援」タブでは、「カラ・レコ開設依頼書」と「カラ・レコ新規利用申込書」のPDFを選択して項目を自動入力できます。資料のファイル名は判定に使用せず、PDF内の記載内容から項目を読み取ります。文字情報を先に読み取り、スキャン画像のページはOCRで処理します。読み取り用ライブラリの取得にインターネット接続が必要ですが、PDFの内容はブラウザー内で処理され、外部へ送信されません。読み取れた項目だけが入力され、既に入力済みの欄は上書きされません。読み取り結果は必ず確認してください。

## GitHub Pages で公開する

1. このフォルダーのファイルを GitHub の **Public** リポジトリにアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選びます。
4. 公開するブランチ（通常は `main`）とフォルダー **/(root)** を選び、**Save** を押します。
5. Pages の設定画面に表示される URL からアクセスします。公開まで数分かかることがあります。

## データとプライバシー

- 入力したメール情報や設定は、ブラウザーの `localStorage` に保存されます。ツール自体はそれらをサーバーへ送信しません。
- PDF読み取り時はPDF/OCR用ライブラリをCDNから取得し、スキャンPDFの場合は日本語データも取得します。読み取るPDFの内容はブラウザー内だけで処理し、CDNやサーバーへ送信しません。
- 共有端末では、入力情報がブラウザーに残る可能性があります。利用後は必要に応じてブラウザーのサイトデータを消去してください。
- 公開サイトは誰でも閲覧できます。実際の顧客情報や個人情報を公開ページに入力したり、公開リポジトリへ登録したりしないでください。
